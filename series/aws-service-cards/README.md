# AWS Service Cards

LinkedIn card series for AWS services.

Each service produces:

- One `Overview` PNG card.
- One `Deep Dive` PNG card.
- Two Markdown prompts.
- Two render templates.
- One LinkedIn post.

## Folders

```text
prompts/    Markdown prompts for each card
templates/  HTML/CSS render templates
images/     Final PNG exports
posts/      LinkedIn post copy
```

## Shared Assets

Use official AWS Architecture Icons from:

```text
../../shared/assets/aws-icons/
```

Do not redraw, recolor, or replace official AWS service icons.
