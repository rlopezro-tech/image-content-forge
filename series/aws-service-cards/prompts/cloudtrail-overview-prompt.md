## SERVICE FOCUS

Record account activity and API usage across AWS.

AWS CloudTrail captures AWS account activity as events so teams can audit access, investigate changes, and support security operations.

## WHAT IS IT?

AWS CloudTrail records user activity and API calls as events, helping answer who did what, where, and when across AWS accounts.

## HOW IT WORKS

1. Activity Happens
   Users, roles, AWS services, SDKs, CLI, or console actions call AWS APIs.

2. Events Are Recorded
   CloudTrail records management, data, network activity, and Insights events.

3. Review Recent Activity
   Event History shows recent management events for the account and Region.

4. Deliver Long-Term Logs
   Trails deliver events to Amazon S3 and can send copies to CloudWatch Logs or EventBridge.

5. Analyze And Respond
   Security and operations teams query, alert, investigate, and automate response.

## INTEGRATES WITH

- Amazon S3: long-term log delivery
- Amazon CloudWatch Logs: monitoring and alerts
- Amazon EventBridge: event-driven response
- AWS Organizations: organization trails

## BENEFITS

- AUDITABLE: Track AWS account activity for governance and compliance.
- INVESTIGATIVE: Identify who changed resources and when.
- CENTRALIZED: Capture activity across accounts with organization trails.
- AUTOMATION READY: Route events to monitoring and response workflows.

## COMMON USE CASES

- Security auditing
- Compliance evidence
- Change investigation
- Operational troubleshooting
