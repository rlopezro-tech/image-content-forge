### Service Focus

Title: SERVICE FOCUS
Main line: Deploy web applications from code or container images.
Body: AWS App Runner turns source code or container images into scalable, managed web services without manually provisioning infrastructure.

### What Is It?

Title: WHAT IS IT?
Body: App Runner connects to a code repository or image registry, builds when needed, deploys the service, and handles running, scaling, and load balancing.

### How It Works

Title: HOW IT WORKS
Use a connected 5-step workflow:

1. Source
   Choose source code or a container image.
2. Configure
   Set runtime, port, build, start, and environment settings.
3. Build
   App Runner builds source code or pulls a ready image.
4. Deploy
   Creates a managed service running containers.
5. Operate
   Handles routing, scaling, health, logs, and updates.
