## SERVICE FOCUS

Run MongoDB-compatible document workloads on AWS.

Amazon DocumentDB is a fully managed document database service with clusters, replicas, managed storage, backups, and AWS security integrations.

## WHAT IS IT?

Amazon DocumentDB is a fast, reliable, fully managed database service that makes it easier to set up, operate, and scale MongoDB-compatible databases in the cloud.

## HOW IT WORKS

1. Connect app
   Applications use MongoDB-compatible drivers and tools.

2. Primary
   Writes go through the primary instance.

3. Storage
   The cluster volume stores data across three Availability Zones.

4. Replicas
   Replica instances scale reads and improve availability.

5. Operate
   Backups, monitoring, encryption, and failover are managed.
