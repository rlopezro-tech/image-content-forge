Service Focus:

- Build, publish, monitor, and secure APIs as the front door to backend services.
- API Gateway supports REST, HTTP, and WebSocket APIs at scale.

What Is It?

- Amazon API Gateway is a fully managed service for creating, deploying, maintaining, monitoring, and securing APIs.
- It connects client applications to AWS Lambda, AWS services, HTTP endpoints, private integrations, and real-time WebSocket backends.

How It Works:

1. Client request
2. Route or method
3. Authorize and throttle
4. Integration backend
5. Response and metrics

Integrates With:

- AWS Lambda: serverless handlers
- AWS IAM / Cognito: authorization
- CloudWatch / X-Ray: logs, metrics, tracing
- VPC Link / HTTP: private and HTTP backends

Benefits:

- Managed API front door
- REST, HTTP, and WebSocket options
- Auth, throttling, and monitoring controls
- Serverless and service integrations

Common Use Cases:

- Serverless APIs
- Microservice entry point
- Mobile and web backends
- Real-time WebSocket apps
