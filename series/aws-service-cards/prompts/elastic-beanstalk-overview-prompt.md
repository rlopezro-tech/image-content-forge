Create a 1080x1350 vertical LinkedIn education card for AWS Elastic Beanstalk.

Visible card text must be in English. Use the official AWS Architecture Icon `shared/assets/aws-icons/Arch_AWS-Elastic-Beanstalk_64.svg`.

## Card Structure

1. Header: AWS Elastic Beanstalk, Overview
2. Service Focus: Deploy and manage web apps without hand-building infrastructure
3. What Is It?: A managed application platform where developers upload code and Elastic Beanstalk provisions, configures, scales, and monitors the AWS resources that run it
4. How It Works workflow:
   - Package app
   - Choose platform
   - Create environment
   - Deploy version
   - Monitor and scale
5. Integrates With:
   - Amazon EC2
   - Elastic Load Balancing
   - Auto Scaling
   - Amazon S3
6. Benefits:
   - Fast deployment
   - Less infrastructure setup
   - Platform choice
   - Full AWS resource control
7. Common Use Cases:
   - Web applications
   - API backends
   - Worker environments
   - Docker apps
   - Prototype to production
   - Managed app hosting
