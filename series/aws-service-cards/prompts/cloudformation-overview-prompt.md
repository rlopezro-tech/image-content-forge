## SERVICE FOCUS

Model, provision, and manage AWS infrastructure as code.

AWS CloudFormation uses templates to create, update, and delete related AWS resources together as stacks.

## WHAT IS IT?

AWS CloudFormation lets you describe AWS resources in YAML or JSON templates and manage those resources as repeatable stacks.

## HOW IT WORKS

1. Author Template
   Define resources, parameters, mappings, outputs, and conditions in YAML or JSON.

2. Create Stack
   Submit the template and parameters so CloudFormation provisions the resources.

3. Update Safely
   Use change sets to preview adds, modifies, deletes, and replacements.

4. Operate Stack
   Monitor events, outputs, resources, drift status, and stack operation results.

5. Evolve Or Delete
   Update, import, refactor, or delete resources through stack operations.

## INTEGRATES WITH

- AWS IAM: permissions and service roles
- Amazon S3: template storage
- AWS Systems Manager: parameter references
- AWS Organizations: StackSets targets

## BENEFITS

- REPEATABLE: Reuse infrastructure definitions across environments.
- CONTROLLED: Manage related resources as one unit.
- REVIEWABLE: Preview proposed updates with change sets.
- CONSISTENT: Detect unmanaged resource drift from templates.

## COMMON USE CASES

- Infrastructure as code
- Multi-environment deployments
- Stack updates and rollbacks
- Compliance configuration baselines
