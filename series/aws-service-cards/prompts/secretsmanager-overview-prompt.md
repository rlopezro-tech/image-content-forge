## Card Content

Header:

- AWS Secrets Manager
- Overview

Service Focus:

- Centrally manage, retrieve, and rotate credentials and application secrets throughout their lifecycle.
- Replace hard-coded secrets with runtime calls from applications and AWS services.

What Is It?

- AWS Secrets Manager helps store and retrieve database credentials, application credentials, OAuth tokens, API keys, and other secrets.
- Secrets are encrypted, versioned, access controlled, auditable, and can be rotated on demand or on a schedule.

How It Works:

1. Store secret
2. Encrypt and version
3. Grant access
4. Retrieve at runtime
5. Rotate and audit

Integrates With:

- AWS KMS: encryption keys
- AWS IAM: access control
- AWS Lambda: custom rotation
- Amazon RDS: managed credentials

Benefits:

- Central secret storage
- Automatic rotation options
- Fine-grained access control
- Audit and replication support

Common Use Cases:

- Database credentials
- API keys
- OAuth tokens
- App configuration secrets
