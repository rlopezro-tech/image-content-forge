### WHAT IS IT?

Amazon SageMaker AI is a fully managed machine learning service. It helps data scientists and developers build, train, and deploy ML models into production-ready hosted environments, with integrated tools for development, training, deployment, governance, and operations.

### HOW IT WORKS

1. Prepare data - Bring data from Amazon S3 or other sources and prepare it for training.
2. Build model - Use notebooks, IDEs, algorithms, frameworks, or low-code tools.
3. Train and tune - Run managed training jobs and optimize model performance.
4. Deploy endpoint - Host models for real-time or batch inference.
5. Monitor and govern - Track quality, logs, lineage, access, and operational behavior.
