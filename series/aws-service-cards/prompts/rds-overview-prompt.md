Title: WHAT IS IT?
Body: RDS provides resizable database capacity for engines such as PostgreSQL, MySQL, MariaDB, Oracle, SQL Server, and Db2. It manages tasks like provisioning, backups, patching, monitoring, and recovery.

### How It Works

1. Choose Engine
   Select a supported relational database engine.
2. Configure DB
   Pick instance class, storage, VPC, and security.
3. Connect App
   Applications connect through the DB endpoint.
4. Operate
   RDS handles backups, patching, monitoring, and recovery.
5. Scale & Protect
   Use Multi-AZ, read replicas, and snapshots.
