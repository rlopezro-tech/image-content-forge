## SERVICE FOCUS

Run code in response to events without managing servers.

AWS Lambda executes function handlers from events, API calls, queues, streams, schedules, and other AWS services.

## WHAT IS IT?

AWS Lambda is a serverless compute service that runs code without provisioning or managing servers. Lambda manages infrastructure, scaling, routing, and execution environments.

## HOW IT WORKS

1. Event source
   An AWS service, API call, or schedule produces an event.

2. Trigger or mapping
   Lambda receives the event directly or through polling.

3. Runtime
   Lambda prepares the event for the configured runtime.

4. Handler
   Function code processes the event.

5. Result
   Output, logs, metrics, and downstream actions are produced.

## INTEGRATES WITH

- Amazon S3: object events

## BENEFITS

- SERVERLESS: No servers to provision or manage.
- EVENT-DRIVEN: Runs from service events and API calls.
- SCALABLE: Scales execution with incoming demand.
- INTEGRATED: Connects with many AWS services.
