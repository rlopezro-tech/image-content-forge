## WHAT IS IT?

AWS Step Functions is a serverless orchestration service for building workflows, also called state machines. Each workflow is made of event-driven states that perform work, control flow, transform data, or make decisions.

## HOW IT WORKS

1. Define workflow
   Model the process in Amazon States Language or Workflow Studio.

2. Start execution
   Invoke the state machine from an API, event, schedule, or application.

3. Run states
   Task and flow states call services, branch, wait, map, or run in parallel.

4. Handle outcomes
   Retry, catch, transform, and pass data between states.

5. Observe result
   Track execution status, history, logs, and metrics.

## INTEGRATES WITH

- AWS Lambda: function tasks
- Amazon ECS: container jobs
- Amazon SQS: message workflows
- Amazon SNS: notifications
- Amazon EventBridge: events and schedules
- Amazon API Gateway: API invocations

## BENEFITS

- SERVERLESS: No workflow servers to operate.
- VISUAL: Design, inspect, and debug workflow steps.
- RESILIENT: Built-in retry and catch behavior.
- INTEGRATED: Calls AWS services and HTTPS APIs.
- AUDITABLE: Execution history shows state-level progress.

## COMMON USE CASES

- Scheduled automation
