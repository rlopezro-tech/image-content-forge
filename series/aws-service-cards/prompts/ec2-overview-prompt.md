### Service Focus

Title: SERVICE FOCUS
Main line: Resizable virtual servers for cloud workloads.
Body: Amazon EC2 provides on-demand compute capacity as instances that you configure with images, instance types, networking, security, and storage.

### What Is It?

Title: WHAT IS IT?
Body: EC2 is a compute service for launching and managing virtual servers in AWS. Each instance starts from an AMI and runs with a selected instance type.

### How It Works

Title: HOW IT WORKS
Use a connected 5-step workflow:

1. AMI
   Choose an image with the operating system and software.
2. Instance Type
   Select compute, memory, network, and storage capacity.
3. Network
   Place the instance in a VPC subnet.
4. Security
   Apply security groups, key pairs, and IAM roles.
5. Run
   Launch, monitor, scale, stop, or terminate.
