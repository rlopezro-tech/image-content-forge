### Service Focus

Run Kubernetes on AWS without managing the Kubernetes control plane.

Amazon Elastic Kubernetes Service is a managed Kubernetes service for deploying, scaling, and operating containerized applications across AWS and hybrid environments.

### WHAT IS IT?

Amazon Elastic Kubernetes Service is a managed Kubernetes service. EKS manages Kubernetes control plane components, while you run workloads on EKS Auto Mode, managed node groups, self-managed nodes, AWS Fargate, or hybrid nodes.

### HOW IT WORKS

1. Container image: Store application images, commonly in Amazon ECR.
2. Kubernetes manifests: Define Deployments, Services, Ingress, and other desired state.
3. EKS cluster: AWS manages Kubernetes API server and control plane availability.
4. Compute nodes: Pods run on Auto Mode, node groups, Fargate, or hybrid nodes.
5. Operate workloads: Use add-ons, load balancing, IAM, VPC networking, and observability.

### INTEGRATES WITH

- Amazon EC2: Node-based compute capacity.
- AWS Fargate: Serverless pod compute with Fargate profiles.
- Amazon ECR: Container image storage.
- Elastic Load Balancing: Ingress and service traffic routing.
- Amazon VPC: Cluster and pod networking.
- AWS IAM: Access control for users and workloads.
- Amazon CloudWatch: Logs, metrics, and monitoring.

### BENEFITS

- MANAGED: AWS manages the Kubernetes control plane.
- KUBERNETES-CONFORMANT: Run compatible Kubernetes applications and tooling.
- FLEXIBLE COMPUTE: Use Auto Mode, managed nodes, self-managed nodes, Fargate, or hybrid nodes.
- AWS-INTEGRATED: Works with AWS networking, security, images, storage, and observability.
