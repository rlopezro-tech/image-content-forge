## Card Content

Header:

- Amazon Route 53
- Overview

Service Focus:

- Highly available and scalable DNS for connecting domains to applications and AWS resources.
- Route 53 supports domain registration, DNS routing, and health checking.

What Is It?

- Amazon Route 53 is a DNS web service that translates domain names into destinations such as IP addresses, load balancers, CloudFront distributions, and other resources.
- Hosted zones contain records that define how traffic should be routed for a domain and its subdomains.

How It Works:

1. Domain query
2. Hosted zone
3. DNS record
4. Routing policy
5. Target resource

Integrates With:

- Elastic Load Balancing: alias records
- Amazon CloudFront: global content delivery
- Amazon S3: static websites
- Amazon VPC: private hosted zones

Benefits:

- Managed authoritative DNS
- Public and private hosted zones
- Flexible routing policies
- Health checks and failover

Common Use Cases:

- Website DNS
- Domain registration
- Multi-region routing
- Private VPC DNS
