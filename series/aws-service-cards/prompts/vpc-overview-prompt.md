## SERVICE FOCUS

Build isolated cloud networks for AWS resources.

Amazon VPC lets you define IP ranges, subnets, routing, gateways, and security controls for workloads in AWS.

## WHAT IS IT?

Amazon VPC, short for Amazon Virtual Private Cloud, lets you launch AWS resources in a logically isolated virtual network that you define. It resembles a traditional network, with AWS infrastructure underneath.

## HOW IT WORKS

1. Define VPC
   Choose a Region and IP address range.

2. Add subnets
   Split the VPC across Availability Zones.

3. Route traffic
   Use route tables to direct traffic.

4. Connect networks
   Attach gateways, endpoints, VPN, or peering.

5. Control access
   Use security groups, network ACLs, and flow logs.

## INTEGRATES WITH

- Amazon EC2: compute in subnets
- Elastic Load Balancing: traffic distribution
- Amazon RDS: private databases
- AWS Site-to-Site VPN: hybrid connectivity

## BENEFITS

- ISOLATED: Define a dedicated virtual network.
- FLEXIBLE: Configure subnets, routes, and gateways.
- SECURE: Layer security groups and network ACLs.
- CONNECTED: Link internet, VPCs, AWS services, and on-premises networks.

## COMMON USE CASES
