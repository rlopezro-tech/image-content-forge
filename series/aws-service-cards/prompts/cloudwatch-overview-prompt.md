## SERVICE FOCUS

Observe applications, infrastructure, and AWS resources.

Amazon CloudWatch collects metrics, logs, traces, alarms, dashboards, and events so teams can detect issues and respond.

## WHAT IS IT?

Amazon CloudWatch monitors AWS resources and applications in real time and provides tools for system-wide observability of performance, operational health, and resource utilization.

## HOW IT WORKS

1. Collect
   AWS services, applications, agents, and OpenTelemetry send telemetry.

2. Store
   Metrics use namespaces and dimensions; logs use log groups and streams.

3. Analyze
   Dashboards, Logs Insights, metrics, traces, and anomaly features expose signals.

4. Alarm
   Alarms evaluate thresholds, metric math, or query results over time.

5. Act
   Notifications, automated actions, and EventBridge events drive response.

## INTEGRATES WITH

- Amazon EC2: host metrics and agent data
- AWS Lambda: function metrics and logs
- Amazon ECS/EKS: Container Insights
- Amazon RDS: database metrics and logs

## BENEFITS

- REAL-TIME VISIBILITY: Monitor resources and applications as they run.
- UNIFIED TELEMETRY: Bring metrics, logs, traces, and events together.
- AUTOMATION READY: Use alarms and events to trigger actions.
- CROSS-ACCOUNT: Centralize observability across accounts and Regions.

## COMMON USE CASES

- Infrastructure monitoring
- Application performance monitoring
- Log analytics and troubleshooting
- Alerting and automated response
