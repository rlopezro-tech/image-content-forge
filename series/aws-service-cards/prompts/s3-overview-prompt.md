### What Is It?

Title: WHAT IS IT?
Body: S3 is an object storage service for storing and retrieving data from anywhere. Buckets hold objects; each object has data, metadata, and a key name.

### How It Works

Title: HOW IT WORKS
Use a connected 5-step workflow:

1. Bucket
   Create a regional container for objects.
2. Object
   Upload data with a key and metadata.
3. Access
   Control access with IAM, bucket policies, and Block Public Access.
4. Manage
   Use versioning, lifecycle, storage classes, and replication.
5. Retrieve
   Access data through console, API, SDK, or events.
