### Service Focus

Deploy, manage, and scale containerized applications on AWS.

Amazon Elastic Container Service is a fully managed container orchestration service for running tasks and services across Fargate, EC2, Managed Instances, and external capacity.

### WHAT IS IT?

Amazon Elastic Container Service is a fully managed container orchestration service. It helps deploy, manage, schedule, and scale containerized applications without operating your own control plane.

### HOW IT WORKS

1. Container image: Build and store an application image, commonly in Amazon ECR.
2. Task definition: Describe containers, ports, CPU, memory, networking, and IAM roles.
3. Cluster capacity: Choose where tasks run: Fargate, EC2, Managed Instances, or external.
4. Service scheduler: Maintain desired task count and replace stopped tasks.
5. Connect and observe: Use load balancing, Service Connect, CloudWatch, and events.

### INTEGRATES WITH

- AWS Fargate: Serverless compute capacity for ECS tasks.
- Amazon EC2: Self-managed instance capacity for ECS clusters.
- Amazon ECR: Container image storage and management.
- Elastic Load Balancing: Routes traffic to ECS services.
- Amazon CloudWatch: Monitors ECS services and tasks.
- AWS IAM: Controls users, services, task roles, and execution roles.
- Amazon VPC: Provides networking, subnets, and security groups.

### BENEFITS

- MANAGED: AWS manages the ECS control plane.
- FLEXIBLE CAPACITY: Run on Fargate, EC2, Managed Instances, or external capacity.
- SCALABLE: Use services and Service Auto Scaling for desired task counts.
- INTEGRATED: Works with AWS networking, security, image, and monitoring services.
