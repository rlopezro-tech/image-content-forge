AWS Identity and Access Management helps manage identities, credentials, and permissions across AWS services and resources.

### WHAT IS IT?

AWS Identity and Access Management is a web service for securely controlling access to AWS services. IAM uses identities, policies, roles, and credentials to authenticate principals and authorize requests.

### HOW IT WORKS

1. Principal signs in: A user, role, federated identity, or service makes a request.
2. Request context: AWS receives the action, resource, principal, and conditions.
3. Policy evaluation: IAM evaluates identity, resource, boundary, session, and organization policies.
4. Allow or deny: Explicit denies override allows; otherwise permissions must allow the action.
5. Access resource: Authorized requests proceed to the target AWS service or resource.
