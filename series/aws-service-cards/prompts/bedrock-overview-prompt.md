### Service Focus

Build generative AI applications with foundation models through a managed AWS service.

### WHAT IS IT?

Amazon Bedrock is a fully managed service that provides access to foundation models from Amazon and leading AI companies through a single API. It includes capabilities for inference, model evaluation, private customization, agents, knowledge bases, guardrails, and generative AI application workflows.

### HOW IT WORKS

1. Application request - Your app sends prompts, messages, documents, or tool instructions.
2. Model choice - Select a foundation model, inference profile, or customized model.
3. Bedrock capabilities - Add knowledge bases, agents, guardrails, prompts, or flows.
4. Managed inference - Amazon Bedrock invokes the selected model and applies configured controls.
5. App response - Return generated text, images, embeddings, summaries, or actions.

### INTEGRATES WITH

- Amazon S3 - data sources and generated artifacts
- AWS IAM - identity and access control
- AWS Lambda - tools and action execution
- Amazon OpenSearch Service - vector search for knowledge bases
- AWS CloudTrail - API activity auditing
- Amazon CloudWatch - logs and operational visibility

### BENEFITS

- MANAGED - Build without managing model infrastructure.
- FLEXIBLE - Choose from multiple foundation models and capabilities.
- SECURE - Use IAM, encryption, VPC options, and private customization patterns.
- RESPONSIBLE - Apply guardrails to inputs and model responses.
