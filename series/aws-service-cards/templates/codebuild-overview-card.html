AWS CodeBuild

Overview

Service Focus

Build and test code without managing build servers.AWS CodeBuild compiles source code, runs tests, and produces deployable artifacts in managed build environments.

What Is It?

A fully managed cloud build service for CI workflows. Define a build project, point it at source code, and let CodeBuild run commands from a buildspec file.

How It Works

1

Source

Repo or S3 input enters the build project.

2

Project

Selects source, environment, artifacts, and logs.

3

Buildspec

YAML commands define build behavior.

4

Build

Managed environment runs tests and commands.

5

Output

Artifacts go to S3; logs stream to CloudWatch.
