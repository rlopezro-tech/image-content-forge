AWS CloudTrail

Deep Dive

Key Takeaways

  • An event records activity in an AWS account.
  • Event History is available by default.
  • Trails deliver selected events to Amazon S3.
  • Organization trails capture activity across accounts.
  • Insights events detect unusual API activity.

When To Use It

Audit account activity and API calls.
Investigate resource changes or denied access.
Deliver audit logs to controlled storage.
Monitor important changes with events.

Watch Out

Event History is account and Region scoped.
It searches only recent management events.
Data events need explicit selectors.
