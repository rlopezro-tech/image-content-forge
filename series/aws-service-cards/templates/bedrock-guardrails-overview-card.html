Amazon Bedrock Guardrails

Overview

Service Focus

Configurable safeguards for generative AI applications. Apply safety, privacy, grounding, and policy controls to user inputs and model responses.

What Is It?

Amazon Bedrock Guardrails evaluates content against configured policies and can return, block, or mask data based on your safeguards.

How It Works

1

Configure Policies

Define filters, topics, PII, grounding, and reasoning checks.

2

Evaluate Input

Check prompts before model inference begins.

3

Invoke Model

Run the FM only when the input passes.

4

Evaluate Response

Inspect output for violations or sensitive data.

5

Return or Block

Return safe content, blocked text, or masked output.
