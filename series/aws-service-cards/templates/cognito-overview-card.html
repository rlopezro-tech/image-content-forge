Amazon Cognito

Overview

Service Focus

Add authentication, authorization, and user access to apps. Cognito provides user pools for sign-up and sign-in, and identity pools for temporary AWS credentials.

What Is It?

Amazon Cognito handles user authentication and authorization for web and mobile apps with user pools, identity pools, app clients, and federation.

How It Works

1

App

A web or mobile app starts sign-up or sign-in.

2

User Pool

Authenticate users directly or through IdPs.

3

Tokens

The app receives JWTs for identity and access.

4

Backend

APIs and apps validate user authorization.

5

AWS Access

Identity pools can issue temporary credentials.
