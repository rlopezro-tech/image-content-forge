AWS Elastic Beanstalk

Deep Dive

Key Takeaways

  • Elastic Beanstalk deploys code and provisions EC2, load balancers, Auto Scaling, and health monitoring.
  • Applications contain versions and one or more environments that run those versions.
  • Platforms define the OS, runtime, web server, app server, and Beanstalk components.
  • Web server environments handle HTTP traffic; worker environments process SQS messages.
  • No extra Beanstalk charge: you pay for the underlying AWS resources.

When To Use It

You want PaaS-style deployment on AWS.
You need Java, .NET, Node.js, PHP, Python, Ruby, Go, or Docker.
You want AWS resources created but still configurable.
You need quick app hosting before custom IaC.

Watch Out

Resources still live in your AWS account.
Platform lifecycle and updates matter.
Manual resource changes can create drift.
Advanced apps may fit ECS, EKS, Lambda, or IaC better.
