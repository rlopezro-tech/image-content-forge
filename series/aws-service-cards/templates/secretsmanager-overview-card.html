AWS Secrets Manager

Overview

Service Focus

Manage secrets across their full lifecycle. Centrally store, retrieve, rotate, and audit credentials, API keys, tokens, and application secrets.

What Is It?

AWS Secrets Manager stores encrypted secrets outside application code and lets applications retrieve current values through AWS APIs and SDKs.

How It Works

1

Store

Create a secret for credentials, keys, or tokens.

2

Protect

Encrypt secret values and track versions.

3

Authorize

IAM and resource policies control access.

4

Retrieve

Applications fetch secrets at runtime.

5

Rotate

Update credentials, audit use, and replicate.
