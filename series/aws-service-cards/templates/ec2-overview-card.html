Amazon EC2

Overview

Service Focus

Resizable virtual servers for cloud workloads. Amazon EC2 provides on-demand compute capacity as instances configured with images, types, networking, security, and storage.

What Is It?

Amazon EC2, short for Amazon Elastic Compute Cloud, lets you launch and manage virtual servers in AWS. Each instance starts from an AMI and runs with a selected instance type.

How It Works

1

AMI

Choose an image with OS and software.

2

Type

Select compute, memory, network, and storage.

3

Network

Place the instance in a VPC subnet.

4

Security

Apply security groups, key pairs, and IAM roles.

5

Run

Launch, monitor, scale, stop, or terminate.
