Amazon ECR

Overview

Service Focus

Store, share, and deploy container images and OCI artifacts. ECR is a managed registry for Docker images, OCI images, and OCI compatible artifacts.

What Is It?

Amazon Elastic Container Registry is a managed container image registry. It provides repositories, IAM-based access, encryption, scanning, and AWS service integration.

How It Works

1

Build

Create a Docker or OCI image in your workflow.

2

Auth

Use AWS credentials and registry login.

3

Push

Store tagged images in a repository.

4

Manage

Apply policies, scanning, lifecycle, and encryption.

5

Pull

ECS, EKS, Lambda, or clients pull for deploys.
