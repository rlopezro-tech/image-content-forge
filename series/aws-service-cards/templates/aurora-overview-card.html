Amazon Aurora

Overview

Service Focus

Run high-performance MySQL- and PostgreSQL-compatible relational databases. Aurora separates compute from distributed storage and manages clusters, replicas, endpoints, backups, and failover.

What Is It?

Amazon Aurora is a fully managed relational database service designed for performance, availability, and compatibility with MySQL and PostgreSQL.

How It Works

1

Cluster

Choose Aurora MySQL or PostgreSQL and create a DB cluster.

2

Instances

Use one writer and replicas for read scale and availability.

3

Endpoints

Writer, reader, instance, or custom endpoints route traffic.

4

Storage

The cluster volume spans AZs and self-heals.

5

Recover

Add readers, use Serverless, fail over, or go global.
