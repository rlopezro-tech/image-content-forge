Amazon DynamoDB

Deep Dive

Key Takeaways

  • Design from access patterns, not relational joins.
  • Primary keys drive placement and efficient reads.
  • GSIs support alternate query patterns.
  • Streams capture item-level changes.
  • Global tables replicate across selected Regions.

When To Use It

High-scale key-value or document workloads.
Serverless apps with managed operations.
Sessions, carts, profiles, game state, IoT metadata.
Event-driven systems with streams and Lambda.

Watch Out

Poor partition keys can create hot partitions.
Scan-heavy access patterns are inefficient.
No relational joins; model data for queries.
