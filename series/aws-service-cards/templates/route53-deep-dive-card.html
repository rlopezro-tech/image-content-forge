Amazon Route 53

Deep Dive

Key Takeaways

  • Route 53 provides authoritative DNS for public and private domains.
  • Hosted zones contain records for domains and subdomains.
  • Records map names to values, aliases, or AWS resources.
  • Routing policies control DNS answers.
  • Health checks can support failover decisions.

When To Use It

Host DNS for internet-facing domains.
Register or transfer domain names.
Route to AWS resources with alias records.
Create private DNS names inside VPCs.

Watch Out

TTL and resolver caching delay visible changes.
Public and private zones solve different problems.
Registrar delegation must use correct name servers.
