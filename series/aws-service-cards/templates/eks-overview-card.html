Amazon EKS

Overview

Service Focus

Run Kubernetes on AWS without managing the control plane. EKS supports Kubernetes workloads across AWS cloud and hybrid environments.

What Is It?

Amazon Elastic Kubernetes Service is a managed Kubernetes service. AWS manages control plane availability while you run workloads on nodes, Fargate, or Auto Mode.
