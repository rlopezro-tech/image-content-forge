Amazon API Gateway

Deep Dive

Key Takeaways

  • API Gateway is the managed front door for API traffic.
  • HTTP APIs fit low-latency RESTful workloads.
  • REST APIs offer a broader feature set.
  • WebSocket APIs support two-way communication.
  • Stages, routes, auth, throttling, and logs shape production behavior.

When To Use It

Expose Lambda through HTTPS APIs.
Put a managed layer before microservices.
Use RESTful APIs with auth and monitoring.
Support WebSocket real-time workloads.

Watch Out

Choose HTTP API vs REST API by feature needs.
Redeploy stage-bound REST or WebSocket changes.
Test CORS, backend errors, mappings, and timeouts.
