AWS CloudFormation

Overview

Service Focus

Model, provision, and manage AWS infrastructure as code. CloudFormation uses templates to create, update, and delete related AWS resources together as stacks.

What Is It?

AWS CloudFormation lets you describe AWS resources in YAML or JSON templates and manage those resources as repeatable stacks.

How It Works

1

Author

Define resources, parameters, outputs, and conditions.

2

Create

Submit a template and parameters to provision a stack.

3

Preview

Change sets show adds, modifies, deletes, and replacements.

4

Operate

Monitor events, outputs, resources, drift, and results.

5

Evolve

Update, import, refactor, or delete through stack operations.
