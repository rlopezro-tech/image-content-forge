AWS Lambda

Deep Dive

Key Takeaways

  • Functions run in response to events or API calls.
  • The handler is the event processing entry point.
  • Runtimes relay events and responses.
  • Execution roles grant AWS resource permissions.
  • Queues and streams use event source mappings.

When To Use It

Event-driven application logic.
API backends with API Gateway.
File, queue, and stream processing.
Scheduled jobs and automation.

Watch Out

Keep handlers idempotent for retries.
Cold starts can affect first-invocation latency.
Execution role permissions must match access.
