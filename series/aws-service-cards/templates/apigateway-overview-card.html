Amazon API Gateway

Overview

Service Focus

Managed API front door for applications and services. Build, publish, monitor, and secure REST, HTTP, and WebSocket APIs at scale.

What Is It?

Amazon API Gateway connects client applications to Lambda, AWS services, HTTP endpoints, private integrations, and real-time WebSocket backends.

How It Works

1

Client

Web, mobile, service, or device sends a request.

2

Route

API method or route selects the API behavior.

3

Control

Authorize, validate, throttle, and apply limits.

4

Integrate

Call Lambda, AWS service, HTTP, or VPC backend.

5

Operate

Return responses with logs, metrics, and traces.
