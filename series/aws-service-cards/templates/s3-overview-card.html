Amazon S3

Overview

Service Focus

Object storage built to retrieve any amount of data.Amazon S3 stores data as objects in buckets, with keys, metadata, access controls, and storage management features.

What Is It?

S3 is an object storage service for storing and retrieving data from anywhere. Buckets hold objects; each object has data, metadata, and a key name.

How It Works

1

2

4

Versioning, lifecycle, storage classes, replication.
