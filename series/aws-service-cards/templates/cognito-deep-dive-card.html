Amazon Cognito

Deep Dive

Key Takeaways

  • User pools authenticate users and issue JWTs.
  • Identity pools issue temporary AWS credentials.
  • App clients define application auth settings.
  • Managed login provides hosted OIDC pages.
  • Lambda triggers customize user pool workflows.

When To Use It

Add sign-up and sign-in to apps.
Federate social, OIDC, or SAML users.
Authorize APIs with user pool tokens.
Grant scoped AWS access to users.

Watch Out

Self-registration opens public sign-up.
Public clients cannot safely hold secrets.
Callback URLs must match the app flow.
IAM roles define actual AWS access.
