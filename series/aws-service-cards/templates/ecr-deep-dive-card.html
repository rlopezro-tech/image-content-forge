Amazon ECR

Deep Dive

Key Takeaways

  • ECR stores images and OCI artifacts; it does not build them.
  • Repositories organize images with tags and digests.
  • IAM and repository policies control push and pull.
  • Lifecycle policies expire or archive images.
  • Replication and pull-through cache support distribution.

When To Use It

Private container images for AWS workloads.
IAM-controlled image sharing across teams.
ECS, EKS, or Lambda container deployments.
Registries needing scanning and lifecycle cleanup.

Watch Out

Tags can move unless immutability is enabled.
Lifecycle rules can remove rollback images.
Cross-account use needs explicit permissions.
