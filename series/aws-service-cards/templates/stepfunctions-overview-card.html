AWS Step Functions

Overview

Service Focus

Orchestrate distributed applications as visual workflows. Step Functions coordinates AWS services, application code, human approvals, and external APIs through state machines.

What Is It?

AWS Step Functions is a serverless orchestration service for workflows, also called state machines. Each workflow is made of event-driven states.

How It Works

1

Define

Model the process in ASL or Workflow Studio.

2

Start

Invoke from an API, event, schedule, or app.

3

Run States

Task and flow states call, branch, wait, map, or parallelize.

4

Handle

Retry, catch, transform, and pass data.

5

Observe

Track execution status, history, logs, and metrics.
