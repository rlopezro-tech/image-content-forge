Amazon DocumentDB

Overview

Service Focus

Run MongoDB-compatible document workloads on AWS. Amazon DocumentDB provides managed clusters, replicas, storage, backups, monitoring, and AWS security integrations.

What Is It?

Amazon DocumentDB is a fast, reliable, fully managed database service for MongoDB-compatible document databases in the cloud.
