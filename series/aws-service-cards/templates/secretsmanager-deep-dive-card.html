AWS Secrets Manager

Deep Dive

Key Takeaways

  • Stores sensitive values outside application code.
  • Applications retrieve secrets dynamically through AWS APIs.
  • Secret versions track updates and rotation states.
  • IAM, resource policies, and KMS control access.
  • Rotation can be managed or implemented with Lambda.

When To Use It

Store database credentials and app secrets.
Replace hard-coded credentials in code.
Rotate credentials without app redeploys.
Replicate secrets for recovery scenarios.

Watch Out

Do not put sensitive values in tags or logs.
Cache secrets carefully for latency and cost.
Rotation must update the secret and target credential.
