Amazon Aurora

Deep Dive

Key Takeaways

  • A DB cluster has a shared cluster volume.
  • The primary DB instance handles writes.
  • Aurora Replicas serve reads and support failover.
  • Endpoints abstract instance changes.
  • Global Database replicates to secondary Regions.

When To Use It

Need MySQL or PostgreSQL compatibility.
Need read scaling through Aurora Replicas.
Need high availability across Availability Zones.
Need global reads or disaster recovery.

Watch Out

Only the primary instance handles writes.
Reader endpoints route reads, not writes.
Secondary global clusters are read-only until promoted.
