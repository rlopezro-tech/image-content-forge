AWS Lambda

Overview

Service Focus

Run code in response to events without managing servers. AWS Lambda executes function handlers from events, API calls, queues, streams, schedules, and other AWS services.

What Is It?

AWS Lambda is a serverless compute service that runs code without provisioning or managing servers. Lambda manages infrastructure and execution environments.

How It Works

1

Event

A service, API call, or schedule produces an event.

2

Trigger

Lambda receives the event directly or by polling.

3

Runtime

Prepares the event for your code.

4

Handler

Function code processes the event.

5

Result

Return output, logs, metrics, or actions.
