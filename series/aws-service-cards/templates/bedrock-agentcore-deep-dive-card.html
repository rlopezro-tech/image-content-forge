Amazon Bedrock AgentCore

Deep Dive

Key Takeaways

  • AgentCore is modular: Runtime, Memory, Gateway, Identity, Observability, Policy, Registry, Evaluations, and Optimization.
  • It works with agent frameworks and models in or outside Amazon Bedrock.
  • Runtime and Harness address session isolation, state, scaling, tools, and observability.
  • Gateway exposes APIs, Lambda functions, services, and MCP servers as tools.
  • Identity and Policy govern what agents can access and under which conditions.

When To Use It

You need agents that run securely at scale.
You want framework and model flexibility.
You need memory, tools, identity, and observability.
You are building an internal agent platform.

Watch Out

Choose Harness vs Runtime intentionally.
Tool access needs permissions and policy boundaries.
Long-running sessions need cost and trace controls.
Agent quality requires evaluations.
