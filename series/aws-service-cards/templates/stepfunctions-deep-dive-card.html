AWS Step Functions

Deep Dive

Key Takeaways

  • Workflows are state machines defined with ASL.
  • Executions are running state machine instances.
  • Task states call services, functions, or HTTPS APIs.
  • Flow states branch, wait, map, pass, or parallelize.
  • Standard and Express fit different workloads.

When To Use It

Coordinate multiple services reliably.
Model auditable business processes.
Add retries, waits, and fallback paths.
Orchestrate data or approval pipelines.

Watch Out

Choose Standard or Express intentionally.
Express supports Request Response integrations.
Retries count as state transitions.
Task tokens must return from same account.
