Amazon CloudFront

Deep Dive

Key Takeaways

  • A distribution is the main configuration object.
  • Origins provide original content.
  • Cache behaviors decide routing and cache policy.
  • Edge locations serve cached objects near viewers.
  • Security can include HTTPS, WAF, signed URLs, and OAC.

When To Use It

Global websites needing lower latency.
Static or dynamic content that benefits from caching.
APIs needing edge routing and protection.
Private content with controlled viewer access.

Watch Out

Broad cache keys reduce cache efficiency.
Invalidations and origin changes need deployment care.
Viewer HTTPS and origin protocol must align.
