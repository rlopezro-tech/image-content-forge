Amazon VPC

Overview

Service Focus

Build isolated cloud networks for AWS resources. Amazon VPC lets you define IP ranges, subnets, routing, gateways, and security controls for workloads in AWS.

What Is It?

Amazon VPC, short for Amazon Virtual Private Cloud, lets you launch AWS resources in a logically isolated virtual network that you define.

How It Works

1

Define VPC

Choose a Region and IP address range.

2

Subnets

Split the network across Availability Zones.

3

Routes

Use route tables to direct traffic.

4

Connect

Attach gateways, endpoints, VPN, or peering.

5

Control

Apply security groups, NACLs, and flow logs.
