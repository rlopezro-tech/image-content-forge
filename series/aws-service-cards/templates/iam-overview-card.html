AWS IAM

Overview

Service Focus

Securely control who can access AWS resources and what they can do. IAM manages identities, credentials, and permissions across AWS services.

What Is It?

AWS Identity and Access Management is a web service for controlling access to AWS services. IAM authenticates principals and authorizes requests with policies.

How It Works

1

Principal

User, role, service, or federated identity signs in.

2

Request

AWS receives action, resource, and context.

3

Policies

IAM evaluates applicable permission policies.

4

Decision

Explicit deny wins; otherwise allow must match.

5

Access

Authorized requests reach the AWS resource.
