AWS CloudFormation

Deep Dive

Key Takeaways

  • Templates are YAML or JSON blueprints.
  • Stacks manage resources as a single unit.
  • Change sets preview proposed updates.
  • Drift detection compares actual and expected state.
  • StackSets deploy across accounts and Regions.

When To Use It

Provision repeatable infrastructure from templates.
Manage create, update, and delete together.
Preview risky updates before applying them.
Deploy baselines across accounts or Regions.

Watch Out

Some updates can replace resources.
Change sets do not guarantee success.
Direct changes can create stack drift.
