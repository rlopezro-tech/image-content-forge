Amazon CloudFront

Overview

Service Focus

Deliver web content, APIs, and media through AWS edge locations. CloudFront is a CDN for global delivery with low latency and high transfer speeds.

What Is It?

Amazon CloudFront speeds up static and dynamic content delivery through edge locations. Distributions define origins, cache behaviors, security, and logging.

How It Works

1

Request

Viewer asks for content through a CloudFront domain.

2

Edge Route

DNS routes to an edge location.

3

Cache

Return cached content when available.

4

Origin

Fetch from S3, ELB, EC2, or HTTP origin.

5

Response

Serve response and cache by policy.
