Amazon Route 53

Overview

Service Focus

Highly available DNS for domains and applications. Route 53 connects user-friendly names to AWS resources, internet endpoints, and private VPC services.

What Is It?

Amazon Route 53 is a scalable DNS web service for domain registration, DNS routing, and health checking across public and private hosted zones.

How It Works

1

Query

A user or resolver asks for a domain name.

2

Hosted Zone

Zone contains DNS records for the domain.

3

Record

A, AAAA, CNAME, alias, or other record matches.

4

Policy

Routing policy decides the DNS answer.

5

Target

Traffic reaches an AWS or external resource.
