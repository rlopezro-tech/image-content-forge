AWS CloudTrail

Overview

Service Focus

Record account activity and API usage across AWS. CloudTrail captures AWS account activity as events so teams can audit access, investigate changes, and support security operations.

What Is It?

AWS CloudTrail records user activity and API calls as events, helping answer who did what, where, and when across AWS accounts.

How It Works

1

Activity

Users, roles, services, SDKs, CLI, or console call AWS APIs.

2

Record

Events capture management, data, network, and Insights activity.

3

Review

Event History shows recent management events by account and Region.

4

Deliver

Trails send selected events to S3, Logs, or EventBridge.

5

Respond

Teams query, alert, investigate, and automate response.
