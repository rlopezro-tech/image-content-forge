# A handoff is not just changing agents—it is transferring responsibility with context

Handoff orchestration routes a task to the specialist best suited to continue it. The key is preserving what has already been learned: task scope, user intent, evidence, constraints, tool history, and the next required action.

A weak handoff makes the receiving agent rediscover the problem. A strong handoff provides a typed envelope and a clear ownership boundary.

Design each handoff with:

- Routing criteria based on capability, permissions, risk, and workload.
- A structured task summary with relevant state and supporting evidence.
- Explicit authority, budget, and action limits for the receiving agent.
- Acceptance checks, escalation paths, and an audit trail of ownership.

Use handoffs when the right expertise emerges during the task—not simply because multiple agents are available.
