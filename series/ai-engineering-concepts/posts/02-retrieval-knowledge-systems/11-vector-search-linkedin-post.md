Vector search is the retrieval primitive behind many AI applications.

Instead of matching only exact words, it searches by semantic closeness. A query and a document can use different language but still land near each other in embedding space.

That makes it useful for support docs, knowledge bases, product catalogs, code search, recommendations, and RAG systems. But vector search is only one part of retrieval quality.

Watch for:
- Poor chunks.
- Weak embeddings for your domain.
- Missing metadata filters.
- High recall but low answer support.
