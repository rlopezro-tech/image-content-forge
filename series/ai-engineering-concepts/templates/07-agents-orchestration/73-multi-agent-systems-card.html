MULTI-AGENT SYSTEMS

ARCHITECTURE PATTERN

OVERVIEW

A multi-agent system coordinates specialized agents around a shared objective. Use it when work genuinely benefits from distinct expertise, independent investigation, or parallel execution—not as a default abstraction.

HOW IT WORKS

1

Receive a
goal

Set scope, outcome, constraints, and accountable owner.

2

Delegate by
role

Route bounded work to the right specialist.

3

Work with
context

Give each agent only the state and tools it needs.

4

Aggregate
evidence

Combine outputs, conflicts, and citations into one view.

5

Validate the
result

Use a controller or reviewer before final delivery.

SYSTEM MAP

ORCHESTRATOR

Owns the user objective, workflow state, budgets, policies, and final response.

Plan + delegate + merge

SPECIALIZED AGENTS

Researcher — find evidence
Analyst — evaluate options
Operator — use scoped tools
Reviewer — check result

SHARED CONTROLS

Role-scoped tools
Typed handoffs
Shared policy + budgets

MERGED OUTCOME

Resolve conflicts, preserve evidence, and return one accountable answer.

Specialize work • constrain handoffs • centralize accountability
