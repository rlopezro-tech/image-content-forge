# Visual Style

Default visual direction for LinkedIn technical content:

- Clear technical diagrams over decorative layouts.
- High information density, but readable on mobile.
- Consistent spacing, alignment, and section hierarchy.
- Final images should use the full usable width of the canvas.
- Avoid stretching icons, text, or generated images.
- Keep visible text concise and specific.

Default canvas:

```text
1080 x 1350
```
