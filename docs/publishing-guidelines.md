# Publishing Guidelines

## Defaults

- Platform: LinkedIn.
- Image format: PNG.
- Primary canvas: `1080 x 1350`.
- Language for visible image text: English, unless a series explicitly says otherwise.
- Post copy: concise, practical, and ready to paste.

## Keep Each Series Consistent

Each series should keep a stable visual language, section pattern, naming convention, and source policy. Shared assets can be reused, but final output files should stay inside the series that owns them.

## Avoid

- Absolute local paths.
- Draft files in the repo root.
- Generated HTML files outside `templates/`.
- Final images outside `images/`.
- Mixing unrelated topics inside one series folder.
